# Pokemon Card Display

This project is a simple web application that displays Pokémon cards and allows users to view detailed information about each Pokémon in a modal.

## Features

- Display a list of Pokémon cards with their names, images, and types.
- View detailed information about each Pokémon, including HP, Attack, and Defense stats, in a modal.
- Responsive design for various screen sizes.

## Technologies Used

- HTML
- CSS
- JavaScript
- [PokéAPI](https://pokeapi.co/)

## Getting Started

To get a local copy up and running, follow these steps:

1. Clone the repository:
    ```sh
    git clone https://github.com/your-username/pokemon-card-display.git
    ```
2. Open the project directory:
    ```sh
    cd pokemon-card-display
    ```
3. Open `index.html` in your web browser.

## Project Structure

- `index.html`: The main HTML file that contains the structure of the web page.
- `style.css`: The CSS file for styling the web page.
- `script.js`: The JavaScript file that fetches Pokémon data and handles the display logic.

## Usage

- Open the `index.html` file in your web browser.
- The page will display a list of Pokémon cards.
- Click the "Details" button on any Pokémon card to view detailed information in a modal.
- Click the close button (`×`) or outside the modal to close it.
